# Hồ sơ kiểm tra lịch sử

Các biên bản ở đây ghi đúng phạm vi và thời điểm đã kiểm, không phải hướng dẫn cài đặt
hoặc baseline thu dữ liệu mới. Kết quả test tổng hợp không thay nghiệm thu bốn VM.
Hướng dẫn đang dùng: [thu dữ liệu](../scenario-collection-runbook.md),
[train](../week3-model-training-runbook.md), [vận hành](../model-operations-runbook.md).
Trạng thái và giới hạn hiện tại: [current-status](../current-status.md).

Các bản hướng dẫn cũ đã được thay thế; Git giữ lịch sử để đối chiếu, không phát lại chúng
cho người thu dữ liệu. Dataset v2 và baseline/tag cũ không được dùng cho đợt thu mới.
